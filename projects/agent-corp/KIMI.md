# Agent Corp - Sistema de Agentes Autônomos

> 🦊 Fluxo contínuo de melhorias via cron

## Visão Geral

Sistema de agentes de IA autônomos operando em modo contínuo.

## Filosofia

```
Task → Done → Next Task → Keep
```

## Workflow

```
feature/* → dev (auto-merge) → main (semanal)
```

## Componentes

- **Cron** (5min): Melhorias automáticas
- **Worker** (10min): Tarefas em background  
- **Guardian** (5min): Monitoramento

## Configuração

Ver `.KIMI` para configurações completas.
