# Contributing to Kaixa Jr

Thank you for your interest in contributing to Kaixa Jr! 🦊

## How to Contribute

### Reporting Bugs

1. Check if the bug is already reported in [Issues](../../issues)
2. Create a new issue with:
   - Clear description
   - Steps to reproduce
   - Expected vs actual behavior
   - Environment details

### Suggesting Features

1. Open a new issue with label `enhancement`
2. Describe the feature and its use case
3. Explain why it would be useful

### Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/amazing-feature`
3. Make your changes
4. Add tests for new functionality
5. Ensure all tests pass: `npm test`
6. Commit with clear message: `[kaixa-YYYYMMDD] Description`
7. Push to your fork
8. Open a Pull Request

## Code Standards

### JavaScript Style

- Use ES6+ features
- Add JSDoc comments
- Handle errors gracefully
- Use meaningful variable names

### Testing

- Write tests for new features
- Maintain >80% coverage
- Test edge cases

### Documentation

- Update README for user-facing changes
- Update architecture docs for structural changes
- Add ADRs for significant decisions

## Development Setup

```bash
# Clone your fork
git clone https://github.com/YOUR_USERNAME/kaixa-jr.git
cd kaixa-jr

# Install dependencies
npm install

# Run tests
npm test

# Start development
npm run dev
```

Feel free to open an issue with the `question` label.
