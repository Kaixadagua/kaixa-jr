# Lições de Progressão Contínua - 2026-02-01

## Contexto
Configurando modo autônomo contínuo para desenvolvimento no Taskemon/Aurahub.

## Barreiras Encontradas e Soluções

### 1. Permissão Git (403 Forbidden)
**Quando:** Tentando push para aura-io-saas/taskemon-city
**Erro:** `Permission denied` / `viewerPermission: READ`
**Solução aplicada:** 
- Verificar permissão com `gh repo view --json viewerPermission`
- Notificar Kaua que precisa de acesso WRITE
- Aguardar configuração antes de continuar
**Lição:** Sempre verificar permissões antes de iniciar workflow

### 2. Connection Timeout (GitHub API)
**Quando:** Criando PR via `gh pr create`
**Erro:** `dial tcp 4.228.31.149:443: connectex: A connection attempt failed`
**Solução aplicada:**
- Retry manual imediato
- Fallback: verificar se PR já foi criado com `gh pr list`
**Lição:** Network é instável - ter fallback local sempre

### 3. Sub-agente Sem Output
**Quando:** Spawn `taskemon-next-task` e `taskemon-continuous`
**Sintoma:** Status "completed successfully" mas sem entregáveis
**Solução aplicada:**
- Não depender de sub-agente para tasks críticas
- Assumir execução manualmente
- Verificar `sessions_history` para debug
**Lição:** Sub-agentes são auxiliares, não obrigatórios

### 4. Repo Movido
**Quando:** Push para origin
**Aviso:** `This repository moved. Please use the new location: aurahub`
**Solução aplicada:**
- Adaptar comandos para novo repo `aura-io-saas/aurahub`
- Verificar se branch existe no novo remote
**Lição:** Ambiente muda - adaptar rapidamente

## Padrões Que Funcionaram

### Loop Contínuo Efetivo
```
Task atual → Detectar done → Commit → Push → PR → Next task
                    ↓ (se blocker)
         Documentar → Fallback → Keep running
```

### Produção Hoje
- 4 PRs criados em sequência
- 0 minutos ociosos
- Tasks: fix → docs → docs completo → a11y

### Workflow Git Eficiente
1. `git checkout -b feat/nome` (criar branch)
2. Fazer mudanças + commit
3. `git push origin feat/nome`
4. `gh pr create` (com reviewer @jup)
5. Immediate next task
