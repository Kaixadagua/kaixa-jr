## 📋 Descrição
**Kaixa Metrics - Dashboard em tempo real para heartbeats**

Script utilitário que exibe métricas consolidadas do sistema em formato compacto:
- **Modo visual**: Dashboard completo com cores e emojis
- **Modo JSON** (`--json`): Para integração com automação  
- **Modo mini** (`--mini`): Ultra-compacto para heartbeats (1 linha)

### Funcionalidades
- Coleta métricas de `metrics.json` e `TRACKING.md`
- Verifica PRs abertos via `gh CLI`
- Calcula backpressure status (🟢🟡🔴)
- Mostra throughput (melhorias/hora)
- Tempo relativo da última melhoria
- Exit code 1 quando backpressure crítico

### Exemplos de uso
```bash
node scripts/kaixa-metrics.js        # Dashboard visual
node scripts/kaixa-metrics.js --json # Output JSON
node scripts/kaixa-metrics.js --mini # 🦊 60melh 🔴13/9 1.2/h
```
