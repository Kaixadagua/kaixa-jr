## Descrição
Criado NotificationSystem - sistema de notificações para eventos importantes:

### Funcionalidades
- **Tipos de notificação**: Urgente, Aviso, Info, Sucesso
- **Eventos monitorados**:
  - Tarefas urgentes
  - Funcionários com energia baixa
  - Tarefas completadas
  - Mudanças de contexto
  - Funcionários estressados
  - Metas atingidas

### Métodos
- `notify()` - Cria notificação genérica
- `urgentTask()` - Alerta de tarefa urgente
- `lowEnergy()` - Funcionário cansado
- `taskCompleted()` - Tarefa concluída
- `contextChanged()` - Contexto alterado
- `stressedEmployee()` - Funcionário estressado
- `milestoneReached()` - Meta atingida

### Gestão
- Marcar como lida
- Filtrar por tipo
- Auto-cleanup (notificações antigas)
- Modo silencioso
- Relatório de notificações
