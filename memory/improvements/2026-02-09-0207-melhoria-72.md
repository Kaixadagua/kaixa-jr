### O que foi criado

Sistema de cache em memória com TTL (Time-To-Live) para otimizar operações repetidas:

- **CacheManager.set(key, value, ttlMs)** - Armazena valor com expiração
- **CacheManager.get(key)** - Recupera se válido
- **CacheManager.has(key)** - Verifica existência
- **CacheManager.memoize(fn, ttlMs)** - Memoização automática de funções
- **CacheManager.getOrSet(key, factory, ttlMs)** - Lazy loading com cache
- **CacheManager.getStats()** - Estatísticas de hit/miss rate

### Por que é útil

```javascript
const cache = require('./scripts/lib/cacheManager');

// Cachear resultado de comando git por 5 min
const status = cache.getOrSet('git-status', () => {
  return execSync('git status --short').toString();
}, 5 * 60 * 1000);
```

- Evita re-execução de comandos caros
- Reduz I/O repetitivo
- Métricas para otimização
