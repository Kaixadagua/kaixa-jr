## 🦊 Melhoria #70 - Sistema de Retry Automático

### Resumo
Implementa sistema de retry com exponential backoff para operações Git, aumentando a resiliência do CI contra falhas transitórias.

### 🆕 Funcionalidades
- **`execWithRetry()`**: Função genérica para execução com retry
  - Até 3 tentativas por padrão
  - Exponential backoff: 1s → 2s → 4s
  - Logging estruturado de cada tentativa
  
- **`updateMetrics()`**: Persistência automática de métricas
  - Incrementa contadores total/local/pr
  - Mantém histórico das últimas 100 execuções
  - Atualiza métricas por tipo (docs, code, etc.)
