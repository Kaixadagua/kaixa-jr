## 📢 Kaixa Notify - Sistema de Notificações Inteligente

### 🆕 Novo Módulo: `scripts/lib/kaixaNotify.js` (354 linhas)
Sistema completo de notificações com múltiplos níveis de severidade e detecção automática de problemas.

#### ✨ Funcionalidades
- **4 níveis de severidade:** INFO, WARNING, ERROR, CRITICAL
- **Console + File output:** Logs coloridos no terminal, persistência em JSONL
- **Check automático de sistema:** `checkSystemStatus()` monitora backpressure, execuções falhas, sessões
- **Histórico persistente:** `memory/notifications/history.jsonl`
- **Relatórios:** Export em Markdown ou JSON
- **CLI completa:** `check`, `history`, `cleanup`, `report`

#### 🎯 Thresholds Configuráveis
| Check | Warning | Critical |
|-------|---------|----------|
| Backpressure | 6 PRs | 9 PRs |
| Failed runs | 2 | 5 |
| Sessões | - | >2 |

### Como usar
```javascript
const notify = require('./scripts/lib/kaixaNotify');
notify.critical('Backpressure crítico!', { prCount: 12 });
notify.checkSystemStatus(); // Verificação automática
```

```bash
node scripts/lib/kaixaNotify.js check
node scripts/lib/kaixaNotify.js report 48  # Últimas 48h
```
