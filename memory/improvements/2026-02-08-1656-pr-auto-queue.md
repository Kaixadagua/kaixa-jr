### O que foi criado
Script inteligente que:
- **Monitora backpressure** em tempo real via GitHub CLI
- **Detecta melhorias locais** candidatas a virar PR (últimos 7 dias)
- **Converte automaticamente** para batch PR quando limite liberar
- **Modo JSON** (`--status`) para integração com outros scripts
- **Modo FORCE** (`--force`) para ignorar backpressure (cuidado!)

### Funcionalidades

```bash
# Verificar status
node scripts/pr-auto-queue.js --status

# Modo normal (respeita backpressure)
node scripts/pr-auto-queue.js

# Forçar criação de PR (ignora backpressure)
node scripts/pr-auto-queue.js --force
```
