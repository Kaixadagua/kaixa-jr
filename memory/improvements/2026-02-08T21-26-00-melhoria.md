## 🚀 Melhoria #60

### O que
Adiciona método `progress()` ao logger para tracking visual de operações longas.

### Por que
Scripts como system-cleanup e backpressure-analyzer processam muitos arquivos. Feedback visual de progresso melhora DX significativamente.

### Como
```javascript
logger.progress('Processando', 5, 10, { itemName: 'arquivo' });
// → 🔄 Processando [█████░░░░░] 5/10 arquivos (50%)
```

### Features
- ✅ Barra de progresso visual (10 segmentos)
- ✅ Atualização inline (não polui terminal)
- ✅ Percentagem e contagem
- ✅ Nome de item configurável
- ✅ Full JSDoc com exemplos
