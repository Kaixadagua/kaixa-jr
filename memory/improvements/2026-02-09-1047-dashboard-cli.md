## 📋 Descrição

Criado `scripts/improvement-dashboard.js` - um dashboard CLI visual para métricas de melhorias do sistema Kaixa Jr.

## 🎯 Problema Resolvido

O sistema tinha muitos dados de melhorias espalhados em arquivos, mas não havia uma forma rápida e visual de ver o estado atual. O guardian mostra dados técnicos, mas faltava uma visão de produto.

## ✅ Implementação

### Novo Script: improvement-dashboard.js
- Estatísticas principais (total, hoje)
- Top dias com barras de progresso ASCII
- Status de backpressure com indicador visual
- Performance dos últimos 10 ciclos
- Lista das últimas 5 melhorias
- Suporte a modo compacto (--compact, -c)

### Atualização: scripts/README.md
- Adicionado dashboard à lista de scripts
- Documentação de uso com exemplos
- Status atualizado para "🆕 Novo"

## 🧪 Como Usar

```bash
# Dashboard completo
node scripts/improvement-dashboard.js

# Modo compacto
node scripts/improvement-dashboard.js --compact
```

## 📝 Notas

- Usa cores ANSI para terminal
- Lê métricas de metrics.json
- Calcula estatísticas em tempo real
- Design inspirado em dashboards CLI como `htop` e `gtop`
