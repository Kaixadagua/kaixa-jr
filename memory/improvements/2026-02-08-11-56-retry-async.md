## Descrição
Função utilitária para executar operações assíncronas com retry automático e backoff exponencial. Essencial para operações de rede ou git que podem falhar transientemente.

## Implementação

```javascript
async function retryAsync(fn, options = {}) {
  const { maxRetries = 3, baseDelay = 1000, maxDelay = 30000 } = options;
  
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const result = await fn();
      ImprovementLogger.info(`✅ Sucesso na tentativa ${attempt}/${maxRetries}`);
      return result;
    } catch (error) {
      const isLastAttempt = attempt === maxRetries;
      
      if (isLastAttempt) throw error;
      
      // Backoff exponencial com jitter
      const delay = Math.min(
        baseDelay * Math.pow(2, attempt - 1) + Math.random() * 1000,
        maxDelay
      );
      
      await new Promise(resolve => setTimeout(resolve, delay));
    }
  }
}
```

## Características
- ✅ Backoff exponencial: delay dobra a cada tentativa
- ✅ Jitter aleatório: evita thundering herd
- ✅ Logging estruturado: visibilidade total
- ✅ Configurável: maxRetries, baseDelay, maxDelay
- ✅ JSDoc completo: autocomplete em IDEs
