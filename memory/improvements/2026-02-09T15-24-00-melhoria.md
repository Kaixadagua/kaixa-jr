## 🆕 formatBytes() + formatDuration() + truncate() - Utilitários de formatação

### Tipo
💻 Code

### Descrição
Criação de `scripts/lib/formatters.js` com funções utilitárias cross-platform para formatação de dados:

- **`formatBytes(bytes, decimals)`** - Converte bytes para representação legível (B/KB/MB/GB/TB/PB)
  - Exemplo: `formatBytes(1536000)` → `"1.46 MB"`
  - Exemplo: `formatBytes(0)` → `"0 B"`

- **`formatDuration(ms)`** - Converte milissegundos para duração legível
  - Exemplo: `formatDuration(3600000)` → `"1h"`
  - Exemplo: `formatDuration(90000)` → `"1m 30s"`

- **`truncate(text, maxLength)`** - Trunca texto com ellipsis
  - Exemplo: `truncate("hello world", 8)` → `"hello..."`
