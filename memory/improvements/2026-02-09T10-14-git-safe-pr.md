## Descrição

Adicionado suporte completo a Pull Requests via GitHub CLI no `git-safe.js`.

### Funcionalidades Adicionadas

1. **createPR()** - Cria PR com opções de:
   - Título customizado
   - Body/descrição
   - Branch base
   - Draft mode
   - Auto-merge

2. **listPRs()** - Lista PRs com filtros:
   - Estado: open/closed/merged
   - Limite de resultados

3. **viewPR()** - Visualiza detalhes do PR

4. **featureComplete()** - Workflow completo em um comando:
   - Cria branch
   - Faz commit
   - Push
   - Abre PR

### Novos Comandos CLI

```bash
# Criar PR
node scripts/git-safe.js pr "título" "descrição"

# Criar draft PR
node scripts/git-safe.js pr-draft "título" "descrição"

# Listar PRs
node scripts/git-safe.js pr-list open 10

# Ver PR atual
node scripts/git-safe.js pr-view

# Workflow completo: branch + commit + push + PR
node scripts/git-safe.js feature-pr feat/x "feat: minha feature"
```
