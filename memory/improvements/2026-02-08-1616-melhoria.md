# Melhoria: Modo Report no Kaixa Guardian

**Data:** 2026-02-08 16:16  
**Tipo:** 💻 Código  
**Local:** 📍 Local (backpressure ativo)

## 🎯 O que foi feito

Adicionado modo `--report` (ou `-r`) ao `kaixa-guardian.js` que gera relatórios em formato Markdown elegantes para Kaua.

### Mudanças

1. **Nova flag `--report|-r`** - Ativa modo de geração de relatório formatado
2. **Função `generateMarkdownReport()`** - Gera output em Markdown com:
   - Data/hora formatada
   - Tabela de métricas do sistema
   - Status de backpressure com contexto
   - Alertas quando presentes
   - Ações recomendadas
3. **Salvamento automático** - Report também salvo em `scripts/reports/report-YYYY-MM-DD.md`
4. **Versão bump** - 1.3.0 → 1.4.0

### Uso

```bash
# Modo silencioso (cron)
node scripts/kaixa-guardian.js --silent

# Modo report (para Kaua)
node scripts/kaixa-guardian.js --report
```

### Exemplo de output

```markdown
# 🦊 Kaixa Guardian Report

**08/02/2026 às 16:16**

## 📊 Status do Sistema

| Métrica | Valor | Limite |
|---------|-------|--------|
| Agentes | 0/2 | ✅ OK |
| Tokens | 0.0k | 360k |

## 📈 Backpressure

🔴 **12 PRs abertos** no aurahub

> ⚠️ Backpressure ativo. Modo local de melhorias em vigor.
```

## 📝 Notas

Esta melhoria facilita o acompanhamento do sistema por Kaua através de relatórios legíveis e bem formatados, sem necessidade de interpretar JSON ou logs brutos.
