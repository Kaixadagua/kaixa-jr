**Data:** 2026-02-09  
**Tipo:** code  
**Status:** ✅ Implementada (local - backpressure ativo)

## Descrição
Script de consolidação de relatórios do Guardian para análise de tendências históricas.

## Arquivos Modificados
- `scripts/guardian-consolidator.js` (novo)
- `scripts/reports/consolidated-trends.json` (gerado)

## Funcionalidades
- Carrega todos os relatórios `guardian-YYYY-MM-DD.json`
- Calcula tendências dos últimos 7 dias
- Métricas: health score médio, PRs abertos médio, total de melhorias
- Indica direção da tendência (📈📉➡️)
- Salva histórico consolidado em JSON

## Uso
```bash
node scripts/guardian-consolidator.js
```
